sourcards-import · 新手指南 仓库

把学习材料变成可导入的 SourCards

这是 sourcards-import 的人读说明。Agent 走 SKILL.md。你把技能装进 agent，浏览器授权一次，然后把笔记丢给它。

1. 安装 2. 登录 3. 制卡 4. 导入

01

把技能装进你的 agent

公开仓是 2Lavine/skill-flashcards。布局是 skills/<name>/SKILL.md，skills.sh 的 CLI 按这个约定扫 GitHub 仓，不用另注册。

skills.sh 
npx skills add 2Lavine/skill-flashcards
npx skills add 2Lavine/skill-flashcards --skill sourcards-import
APM 
apm install 2Lavine/skill-flashcards
  • Codex plugin：把仓库根目录（含 .codex-plugin/plugin.json）装成插件。
  • 复制目录：把 skills/sourcards-import 放到 .agents/skills/ 或 .claude/skills/。
  • 校验：在仓库根执行 npm test。制卡规则在 SKILL.md，人不用背。

02

浏览器授权，不要复制令牌

导入、目录交叉校验、回滚都要 Personal Integration Token。让 agent 跑登录脚本；浏览器打开授权页，核对这些字符，点授权。脚本写入 gitignored 的 .env.local，终端不会打印 sc_int_…。

login.mjs 
node skills/sourcards-import/scripts/login.mjs

在浏览器里核对这些字符

K7M2-Q9XW

  • 导入 / 列出批次 / 回滚
  • 读牌组与分类名（不含卡片正文）
  • 聚合复习统计
  1. 终端出现 user code；浏览器应打开 /cli/authorize。
  2. 未登录就先登录 SourCards，确认代码一致后点授权。
  3. 看到 saved FLASHCARD_API_KEY to …/.env.local 即完成。不要 cat 这个文件。

浏览器打不开时加 --no-open，把打印出的 URL 贴进浏览器。拒绝浏览器登录时，到 App「设置 → 集成 → Personal Integration Tokens」创建一次令牌，再用 save-token.mjs 写入。

03

把材料交给 agent，先 lint 再导入

对 agent 说「用 sourcards-import 把这篇笔记制成卡片」。它按效用优先出卡，写出 JSON，再跑 lint。示例模板：仓库里的 examples/cards.json。

lint-cards.mjs 
node skills/sourcards-import/scripts/lint-cards.mjs examples/cards.json
  • 退出码 1：JSON 或必填字段坏了，修好再导入。
  • 退出码 0 带警告：分类带 /、缺 alias: 这类质量漂移，尽量先改。
  • 退出码 0 且干净：可以导入。加 --catalog https://sourcard.sourmonkey.xyz 会用你的牌库交叉核对（需要 token）。

04

导入一批；导错了就回滚这批

Agent 用已保存的 FLASHCARD_API_KEY 调 POST /api/import。单次最多 200 张。响应里的 importId 用来整批撤销。

POST /api/import 
curl -s -X POST https://sourcard.sourmonkey.xyz/api/import \
  -H "Content-Type: application/json" \
  -H "x-api-key: $FLASHCARD_API_KEY" \
  -d @examples/cards.json
rollback 
curl -s -X POST https://sourcard.sourmonkey.xyz/api/imports/IMPORT_ID/rollback \
  -H "x-api-key: $FLASHCARD_API_KEY"

找不到 importId 时：GET /api/imports，按时间或 sourceUri 过滤。令牌读不到卡片正文。没 token 时让 agent 把 JSON 交你在 App 里手动导入。

还要知道的

这个技能能访问我的复习记录吗？

不能。令牌只有导入、列出/回滚批次、读牌组分类名、聚合统计。没有卡片正文、原始复习日志、Coach、设置或账户。

skills.sh 和 APM 装的是同一套东西吗？

是。公开仓里的三份技能：sourcards-import、sourcards-library-lint、sourcards-daily-report。npx skills add 按 Git 目录约定安装；apm install 读根上的 apm.yml，把同一份目录落到当前 agent 的 skills 路径。已经在用 APM 的项目用 APM；其他环境用 skills.sh。两者都不替代这个公开仓。

登录脚本已经提示 key is set，还要再跑吗？

不用。环境变量或技能目录 .env.local 里已有 key 时，login.mjs 直接退出。换账号或令牌失效再 --force。
